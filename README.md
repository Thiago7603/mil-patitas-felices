# Mil Patitas Felices 🐾

Una plataforma web para conectar refugios, adoptantes y amantes de los animales, facilitando la adopción responsable y el cuidado de mascotas.

![Banner](https://cdn.phototourl.com/uploads/2026-02-26-0481510e-afd2-4616-966c-b594722d3f23.png)  

## ✨ Características principales (en desarrollo)

- Registro y perfiles para adoptantes y refugios
- Publicación y búsqueda de mascotas en adopción
- Sistema de mensajes o contacto directo
- Filtros avanzados (edad, tamaño, ubicación, etc.)
- Panel de administración básico para refugios
- Diseño responsive y moderno

## 🛠️ Tecnologías utilizadas

### Frontend
- **Vue 3** + **Composition API**

### Backend (en desarrollo)

## 🚀 Instalación y ejecución local

### Prerrequisitos
- Node.js ≥ 18
- npm / pnpm / yarn

### Pasos

1. Clona el repositorio
   ```bash
   git clone https://github.com/Thiago7603/mil-patitas-felices.git
   cd mil-patitas-felices

2. Ejecutar en la terminal:
   ```bash
   npm install
   
3. Acceder a la carpeta frontend:
   ```bash
   cd frontend

4. Instalar librerias y dependencias, en el frontend desde la terminal:
   ```bash
   npm install

5. Ejecutar el proyecto estando en la carpeta del frontend:
   ```bash
   npm run dev

6. Copiar el link http que aparece en la terminal y ponerlo en el navegador. El link de la terminal es similar a este:

      ```bash
   http://localhost:5173/
